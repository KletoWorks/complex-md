## Why these files are hot

fastify.js is the 958-line factory behind every instance. It validates options, builds the router, server and 404 handler, and stores internal state under keys from lib/symbols.js. It also defines the public API: route shorthands, addHook, inject, ready and close. It changed in 210 commits, and 52 of them were fixes. 187 test files reach it, for example test/404s.test.js and test/500s.test.js. Before editing this file, open lib/route.js alongside it.

lib/errors.js defines every FST_ERR code with @fastify/error: a name, a message template, a status code and an error class. 16 files import it. Users and tests match on these codes, so a renamed code or a changed status breaks the public API. 17 of its 43 commits were fixes. Before editing this file, run test/internals/errors.test.js.

lib/reply.js implements the Reply object. Its send() method picks a content type and a path for each payload kind: stream, web stream, Response, buffer, string or JSON. It then runs the preSerialization, onSend and onError hooks. Only 3 files import it, but every response passes through it. 36 of its 86 commits were fixes, which is 42%. Before editing this file, run the tests in test/diagnostics-channel/.

lib/symbols.js is a 66-line map of Symbol keys for the internal state of instances, requests and replies. 18 files import it, the most of any file. A removed or renamed key gives undefined at each read site and throws no error. Before editing this file, search all 18 dependents for each key that you change.

lib/hooks.js lists the supported hooks and runs them. The hook arrays, the Hooks constructor and buildHooks each name every hook by hand, so a new hook needs 3 edits. buildHooks copies lifecycle hooks to child contexts but gives them empty onReady, onListen and preClose lists. 7 files import it, and only 3 test files reach it. Before editing this file, run test/internals/hooks.test.js and test/internals/hook-runner.test.js.
