How it works

1.Run it once

In any git repository, run npx complex-md. It reads the commit history and the dependency graph, and writes COMPLEX.md at the root. No Node.js? Hand your agent the skill, which does the same analysis with git alone.

2.It wires itself in

One marked line near the top of AGENTS.md sends your agent to the map before it edits a listed file. --profile full adds a brief per hot file where each agent looks. Hooks come only with --hooks.

3.Your agent reads before it edits

Each hot file gets one instruction: what to open with it, and which tests to run. Run it again after big changes; npx complex-md verify tells you when the map has drifted.

Works with the agents you already use.

Claude Code and Cursor get rules, and hooks on request. GitHub Copilot, OpenHands, Windsurf and Cline get a rule per hot file. Every other agent here reads COMPLEX.md through AGENTS.md or its own instructions file.

FAQ

How is this different from AGENTS.md?

AGENTS.md says how to work in the project. COMPLEX.md says where the risk is. One line in AGENTS.md sends the agent to it.

Do I need an API key?

No. Without a key, the file gets template prose built from the numbers, and your agent can rewrite it from .complex-md/prompt.md. With a key, one model call writes the prose.

What does it send, and where?

Without a key, nothing: the CLI computes the map with git and Node.js and sends no telemetry. With a key, it makes one call to the provider you chose, with the computed signals and excerpts of up to ten hotspot files, about 60,000 characters of code at most. With --via, the same request goes to the agent CLI you named.

Who writes the prose?

The numbers always come from git. The prose comes from one model call when a key is set, from your own agent CLI with --via, or else from a template built from the numbers. A template writes every sentence on a hosted page.

What does the score mean?

A ranking, not a prediction. Higher means an edit has more ways to go wrong. The spec shows the formula.

Will it get in my agent's way?

A default run writes COMPLEX.md, one marked line near the top of AGENTS.md, a marked block in .gitattributes and .complex-md/manifest.json. It writes no hooks unless you pass --hooks, and --no-wire writes only the file. --profile full adds at most 10 briefs per agent, in .claude/rules/complex-md/, .cursor/rules/complex-md/, .github/instructions/complex-md/, .agents/skills/, .agents/rules/, .devin/rules/, .windsurf/rules/, .kiro/steering/ and .clinerules/. npx complex-md unwire removes what wire wrote and names any file you edited since.

How does a maintainer remove a hosted page?

In one of three ways: commit COMPLEX.md to the repository, set hosted: false in its front matter, or send the removal form. Each takes effect within 24 hours.

Does it work outside GitHub?

The CLI works on any git repository, wherever it is hosted. Hosted pages and the lookup cover public GitHub repositories only, for now.

Can I write one by hand?

Yes. It is plain markdown with a YAML header. The walkthrough takes seven git commands.

npx says "No versions available". Why?

Your npm config sets min-release-age, which refuses packages published this week. Run npm_config_min_release_age=0 npx -y complex-md once.
