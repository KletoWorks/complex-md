Look up a repository's map

Paste a public repository from GitHub, GitLab, Codeberg or Bitbucket. A mapped repository opens its page: the files where edits break things, the tests to run before editing them and the files that change together. Hosted pages cover GitHub repositories first.

Takes owner/name for GitHub, or a URL or SSH remote from github.com, gitlab.com, codeberg.org or bitbucket.org, such as fastify/fastify or https://codeberg.org/forgejo/forgejo.

$npx complex-md

It computes the map from the repository's own history and writes COMPLEX.md at its root.

How a repository gets a page

complex.md computes maps of a set of public GitHub repositories ahead of time, from their git history. Each request for a repository counts toward the next set. Requests for GitLab, Codeberg and Bitbucket repositories are counted too. The command works in a clone from any host. Every hosted page asks the repository's maintainers to commit the file, and a committed file replaces the page.

Who writes the prose?

A template. It builds every sentence on a hosted page from the computed numbers. No model and no person writes a hosted page.

Removing a page

A maintainer can remove the page of a repository in three ways, and each takes effect within 24 hours. The removal page lists them.
