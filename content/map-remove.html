Remove a hosted map page

A hosted page on complex.md shows the map of one public repository. There are three ways to take a page down, and each takes effect within 24 hours.

  1. Commit COMPLEX.md to the repository. Run npx complex-md in a clone and commit the file. The page then gives way to a link to the committed file.
  2. Set hosted: false in its front matter. Add the line to the front matter of the COMPLEX.md you commit. complex.md then builds no page for the repository.
  3. Send this form. A request needs no reason.

The repository whose page should go, as owner/name or a GitHub URL.

Up to 2,000 characters. A reason helps improve the pages.

Who writes the prose?

A template builds every sentence on a hosted page from numbers computed from the repository's public git history. No model and no person writes a hosted page, and a page never compares one repository with another.
